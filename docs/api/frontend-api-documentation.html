PharmaTraK Documentation Overview

Frontend-Backend API Integration Reference

This documentation provides a comprehensive mapping of React frontend components to their corresponding backend API endpoints, including data structures, function calls, and file references.

Data Flow

Frontend Component → API Service → HTTP Request → Backend Route → Controller Function → Database Model

Key Statistics
  • 24 Main Components
  • 14 Reusable Components
  • 45+ API Endpoints
  • JWT Authentication
  • 3 User Roles

Application Architecture

Frontend Stack

  • React 18 - Component framework
  • React Router - Client-side routing
  • Bootstrap 5 - UI framework
  • Axios - HTTP client
  • Context API - State management

API Service Structure

frontend/src/services/api.js
  • authAPI - Authentication services
  • userAPI - User management
  • storeAPI - Store operations
  • drugAPI - Drug database & FDA
  • inventoryAPI - Inventory management
  • auditAPI - Reporting & audit

Backend Stack

  • Node.js & Express - Server framework
  • MySQL - Database
  • JWT - Authentication tokens
  • bcrypt - Password hashing
  • CORS - Cross-origin support

API Base Configuration

Base URL: http://localhost:3001/api
Authentication: Bearer JWT Token
Content-Type: application/json
