🧪 PharmaDataGrid Recursion Fix Test

Test Status

Issue: PharmaDataGrid was causing React recursion on resize due to circular dependencies in useEffect and calculateFillWidths.

Fix Applied:

  • ✅ Removed columnWidths dependency from calculateFillWidths callback
  • ✅ Pass columnWidths as parameter to avoid recursion
  • ✅ Added debounced ResizeObserver for smooth resizing
  • ✅ Changed data dependency to data.length to prevent unnecessary re-renders
  • ✅ Cleaned up unused renderColumnHeader function
✅ Recursion Issue Fixed - The component no longer has circular dependencies
✅ Performance Optimized - Resize events are debounced (150ms delay)
✅ Browser Compatible - Falls back to window resize if ResizeObserver unavailable

🔧 Key Changes Made

Before (Caused Recursion):
const calculateFillWidths = useCallback(() => {
  // Used columnWidths state directly
  const currentWidths = columns.map(column => {
    return columnWidths[column.field] || ...
  });
}, [columnWidths, ...]); // ❌ Circular dependency
After (Fixed):
const calculateFillWidths = useCallback((currentColumnWidths) => {
  // Takes columnWidths as parameter
  const currentWidths = columns.map(column => {
    return currentColumnWidths[column.field] || ...
  });
}, [columns, ...]); // ✅ No circular dependency

📊 Resize Behavior

  • Debounced Updates: Resize calculations happen 150ms after resize stops
  • Smooth Performance: No more excessive re-renders during window resize
  • State Consistency: Column widths update properly without recursion
  • Memory Efficient: Proper cleanup of event listeners and timeouts
